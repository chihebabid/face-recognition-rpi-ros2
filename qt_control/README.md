# control_cam_v2

A Qt-based GUI application for controlling a camera in a ROS 2 environment.

## Features

- **Camera Control**: Capture and manage camera streams
- **Servo Control**: Control servo motors (manual and automatic)
- **Servo Supervision**: Monitor servo status



## Dependencies

- Qt 6.9+
- ROS 2 
- OpenCV
- cv_bridge
- image_transport
